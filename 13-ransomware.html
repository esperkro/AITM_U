Act 03 · Attachment triage

Which files would you open?

All of these arrived as attachments. Some are routine. Some are loaded weapons. Sort them — and read the note on each one.

Payment_Receipt.pdf.exe
From: unknown sender · 212 KB
Double extension. Windows hides known extensions by default, so this shows as "Payment_Receipt.pdf". The real extension is .exe — a program.
Q3_Budget_Review.xlsx
From: your manager · you asked for it this morning
Expected file, expected sender, expected format. Context is the best filter. Still: if it ever asks you to enable macros or editing to "view", stop.
Shipping_Label.iso
From: "Courier Notifications" · 1.2 MB
Disk image. .iso, .img and .vhd files mount like a drive and are used to smuggle programs and shortcuts past protections. Nobody sends shipping labels this way.
Scanned_Contract.html
From: "DocuSign Service" · 9 KB
HTML attachment. Opens locally in your browser — often a fake sign-in page or a script that assembles malware on your machine ("HTML smuggling"). Real e-signature services send links to their own site.
Resume_JSmith.docm
From: careers inbox applicant · 64 KB
The "m" means macros. .docm, .xlsm and .pptm are macro-enabled formats. A résumé has zero reason to contain code.
Team_Photos.lnk
From: a coworker's address · 2 KB
Shortcut file — and possibly a compromised coworker. A .lnk can launch any command. Attackers often send from real, hijacked accounts. Verify with the coworker on another channel.
Meeting_Notes.pdf
From: colleague · follow-up to today's meeting you attended
Reasonable. Expected sender, expected topic, plain PDF. If a PDF ever shows a "click here to view the document" button that leads to a login page, treat it as phishing.
Make your computer show the truth. In Windows File Explorer: View → Show → File name extensions. On a Mac: Finder → Settings → Advanced → Show all filename extensions. It takes ten seconds and exposes every double-extension trick.
Act 04 · If someone clicks

How one click becomes a lockout.

FRIDAY 16:58
Macro runs. A small loader quietly downloads a remote-access tool.
FRIDAY → SUNDAY
Attackers explore. They steal passwords, find file servers and backups, and copy sensitive data out.
SUNDAY 02:00
Backups deleted, encryption starts — timed for when nobody is watching.
MONDAY 07:30
Ransom note on every screen. Pay, or the files stay locked and the stolen data gets published.

Every hour between the click and the report gives the attacker more room. A report at 16:59 Friday changes the whole story.

RULE 01
Never "Enable Content".
No invoice, résumé, or shipping notice needs macros to be read. If a document begs you to enable something, that's the attack.
RULE 02
Fear unusual file types.
.zip with a password, .iso, .img, .html, .lnk, .js, .exe, .docm/.xlsm — and any double extension. Expect plain PDFs and Office files from known people.
RULE 03
Verify the unexpected.
An invoice you didn't expect? Check with the vendor using contact details you already have — not the ones in the email.
RULE 04
Clicked? Report in minutes.
Tell IT immediately, even if "nothing happened". If instructed, disconnect from Wi-Fi/network — but don't power off; responders may need what's in memory.
RULE 05
Save work where it's backed up.
Use approved company storage (OneDrive/SharePoint/network drives), not your desktop. Backed-up data is what lets a company recover without paying.
Ransomware is a Monday-morning disaster that starts with a Friday-afternoon click. Don't be the click — be the report.
